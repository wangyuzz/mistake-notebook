# 拾题 · Mistake Notebook

面向手机浏览器的多用户错题本。React + TypeScript + Vite，Express API，PostgreSQL，直接调用兼容 Chat Completions 的视觉 API。

## 功能

- 独立账号与学习空间：每位用户拥有自己的错题、分类、原图、笔记和复习记录；管理员可创建账号、停用用户、配置全站 AI 服务，管理接口不读取他人的错题正文。
- 主屏幕图标：采用页面同色系的浅鼠尾草绿底色、翻开的书和书签图案，提供 iPhone 180px 图标、浏览器 SVG / PNG 图标，以及 192 / 512px Web App 图标。支持从 Safari 添加到主屏幕，以独立窗口打开；不提供离线访问。图标由 public/favicon.svg 生成，设计更新时可在有 Chrome 的开发环境执行 npm run icons:generate，部署直接使用已生成的 PNG。
- 首次启动创建管理员，无默认密码。原单用户版本的本地 / PostgreSQL 错题，在首位管理员建立时接收到其空间中；新用户从空空间开始。
- 开放注册：首位管理员创建后，任何访客均可从登录页自主注册，无需邀请；新账号固定为普通用户，注册成功自动登录。
- 管理控制台默认打开“用户与使用情况”：查看总用户数、今日新增、今日 / 近 7 天活跃、现存错题总量和今日 AI 请求；支持搜索与状态筛选，每位用户展示错题、已掌握、复习次数、导入整页数、AI 请求、注册 / 最近登录 / 最近使用时间及注册来源，可直接停用或启用账号。页面每分钟刷新，登录与活跃时间从更新后开始积累，约每分钟记录一次；用户日期按北京时间，AI 请求按既有 UTC 日额度统计，失败和中止请求也计数。统计接口仅管理员可访问，仅返回汇总数据。
- 整页拍照 / 相册导入：自动或手动拆题、移动 / 缩放裁框、撤销、旋转、勾选题目；标题、分类、标签和题目文字直接在裁框页面编辑。支持继续追加图片、切换图片保留编辑内容，统一批量收录（事务写入）。每张最多 10 题，一批最多 20 张，原图最大 20MB、50MP；单批原图 data URL 合计最多 40MB、提交总量小于 58MB。
- 整页原图保存一次，单题从原图分辨率裁出，保留图形、选项和批注。题目详情可回看整页。删单题不会删除来源整页，原图仍可随完整备份导出。
- 单题手动录入，题目和解析图片各最多 4 张；文字解析、答案、标签、笔记放在一起。该入口会压缩图片，整页导入则保留上传原文件。
- 整页框题页面直接编辑题目、题目选项、我的错误答案、正确答案和答案解析，切图时保留草稿并一起收录；独立编辑页采用同一套答案与解析表单。“图片转文字”可上传最多 4 张解析图片，保留图片并将识别文字追加到可编辑解析中，共用拆题识别模型和思考等级；“AI 生成解析”根据当前裁出的题目、选项及参考资料流式生成，支持停止、保留部分结果与 Markdown / 公式预览。两种能力都计入既有 AI 日额度。
- 拆题识别请求自动附加题干 / 选项分离的输出格式约定，后台提示词区可查看实际附加内容，旧模板也兼容。前后端共用文字整理逻辑，修正双重转义换行，将混入题干的 A / B / C 等选项分离到独立输入框；保留数学公式与代码中的反斜杠。
- 分类、搜索、收藏、状态筛选、复习和错题关联 AI 对话；AI 解析由用户确认后存入，保留原内容。
- 错题详情支持上一题 / 下一题与当前位置，沿用打开时的筛选和排序；修改复习状态后仍可按原顺序继续浏览。切题自动保存未提交的复盘笔记，保存失败时留在当前题。专注复习也支持前后切换，标记失败不会跳题。详情与整页导入采用固定头尾、内容区滚动的弹窗布局，避免粘性底栏在滚动后留下空白。
- 管理后台实时保存 AI 地址、密钥、对话 / 拆题模型、自动识别开关、请求额度和超时；API 密钥加密保存，不返回完整密钥。控制台还可查看、编辑、恢复默认的识别与辅导提示词，以及设置解题 / 拆题各自的模型思考等级。
- 每位用户可导出自己的完整 JSON 备份，包含单题和来源整页；提供指定目标账号的 PostgreSQL 恢复 / 迁移脚本。

## 运行

需要 Node.js 22.12+（建议 24）。

```sh
npm ci
# 首次运行创建本地配置，勿将 .env 提交到 GitHub。
cp .env.example .env
npm run build
npm start
```

打开 http://127.0.0.1:3001，创建首位管理员。点击“拍照导入”，选择拍照或上传自己的照片开始整理。已有账号从登录页进入；新用户点击“注册新账号”自主注册，管理员也可以在控制台手动添加普通用户或其他管理员。

开发模式：npm run dev（页面 5173，API 3001）。首次运行前请先安装依赖；开发与生产环境请使用独立的数据和配置。

## 存储与 PostgreSQL

.env 的 DATABASE_URL 留空时，使用持久化 data/demo.json；本地模式中的六道虚构示例题由首位管理员接收，示例配图为项目自制素材。填写 PostgreSQL 连接并重启即可使用数据库：

```dotenv
DATABASE_URL=postgresql://用户:密码@127.0.0.1:5432/shiti
DATABASE_SSL=false
```

自动建立 platform_users、platform_sessions、platform_settings、workspace_categories、workspace_questions、workspace_pages 和 ai_usage。学习资料以 JSONB 保存，分类具有复合归属外键。图片目前存为 data URL；大规模部署可改对象存储。两种存储相互独立，切换后需建立目标账号并迁移学习资料。

账号密码采用带随机盐的 scrypt；Cookie 为 HttpOnly / SameSite=Strict，会话有效期七天。停用账号或修改密码会撤销旧会话。

管理接口 `/api/admin` 统一校验服务端会话与管理员角色，普通用户直接请求管理地址也不能获取用户列表、用量、提示词或修改配置。公开注册固定创建普通用户，初始化完成后不能再次创建首位管理员。错题、来源原图、AI 关联题目与导出均按当前用户隔离，前端隐藏入口不作为权限依据。写请求校验来源并拒绝跨站请求，页面禁止被 iframe 嵌入。Markdown 只将外部 HTTP(S) 引用渲染为可点击链接，站内路径按文字展示。

首页依次显示今天收录（北京时间）、待复习（未掌握）和总收录。AI 报错保留在对话页；只有管理员遇到配置类错误时才显示“检查 AI 配置”，点击后直接进入 AI 配置页。

恢复 / 迁移到 PostgreSQL：先设置 DATABASE_URL、重启网站，并创建接收资料的账号，然后执行：

```sh
# 设置页导出的个人备份，或旧版单用户数据
npm run migrate:demo -- ./备份.json 目标用户名
# 新版本地多用户数据需指明来源账号
npm run migrate:demo -- ./data/demo.json 数据库目标用户名 本地来源用户名
```

全量校验后在事务中导入，按分类名称匹配，保留整页来源关系，不覆盖已有题目，重复导入同一备份会去重。源文件保留；账号密码和 AI 配置不随个人备份迁移。备份缺少来源整页会报错，避免无声丢失来源。

## AI 与环境变量

管理员在网页设置中配置兼容 Chat Completions 的服务地址、API Key 和支持视觉的模型。识别与解题可采用不同模型，识别模型留空时共用对话模型。后台保存后立即生效，无需重启。思考等级通过 reasoning_effort 传给 API，默认不传该参数；拆题可沿用解题等级，也可单独指定。支持哪些等级取决于具体模型，参数不被上游接受时会显示错误，不自动降级重试。官方参数说明：https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create 。

提示词区展示七份实际模板：识别系统提示词、识别任务模板、解析图片转文字的系统与任务提示词、辅导系统提示词、题目资料模板和单题解析任务。模板变量 {{width}}、{{height}}、{{categories}}、{{question}} 会在请求时替换。保留拆题 JSON 格式和归一化 bbox 规则，解析器仍会校验返回结构。恢复默认只修改当前表单，保存后生效。对话还会附带历史与用户输入；图片作为独立的 image_url 消息发送。

服务端 POST 到配置地址 + /chat/completions，Bearer 认证、image_url 传图。自动识别默认开启，仅识别题目边界、可读题干与分类建议；随后人工核对收录。图形始终保留裁图，手写答案不当作正确答案。未配置 / 识别失败时可以手动框题，不生成模拟识别或解题内容。

.env 的 AI_API_BASE_URL、AI_API_KEY、AI_MODEL、AI_RECOGNITION_MODEL、AI_TIMEOUT_MS 仅作首次默认值；管理员保存过设置后，以数据库配置为准。数据库连接、HOST、PORT、COOKIE_SECURE、SETUP_TOKEN 和 SETTINGS_ENCRYPTION_KEY 由部署环境管理，修改后重启，不提供网页任意编辑 .env 的接口。

SETTINGS_ENCRYPTION_KEY 用于加密 AI 密钥，应保持固定并备份。留空时自动生成 data/settings.key，迁移服务器必须同时带走此文件；个人错题备份不包含该文件。更换或丢失主密钥会导致原 AI 配置无法解密。

可选 SETUP_TOKEN 限制首位管理员初始化。HTTPS 部署将 COOKIE_SECURE=true。请求支持取消、超时、重试与每账号分钟 / 每日额度；每日按 UTC 日期统计，失败的上游请求也计入额度。AI 对话与单题解析通过 SSE 边接收边显示，支持停止生成并保留部分回复，Markdown 与数学公式会渲染为排版内容；整页拆题仍需接收完整 JSON 后校验裁框。MinerU / PDF 批量解析、透视校正和手写擦除暂未实现。

## 手机与容器

Linux 首次部署见 [DEPLOY-LINUX.md](./DEPLOY-LINUX.md)。源码部署包可通过 `npm run package:linux` 生成到 releases，排除本地账号、错题和密钥。

同一 Wi-Fi 手机访问时，将 HOST 改为 0.0.0.0 并重启，打开 http://电脑局域网IP:3001，防火墙放行该端口。拍照使用手机原生文件拍摄入口，浏览器支持取决于设备；也可从相册选择。公网使用 HTTPS 反向代理。

```sh
sh deploy/init.sh # 仅在没有 .env 的新服务器上执行
docker compose up --build -d
```

Compose 启动 PostgreSQL 17 和网站，数据库保存在 postgres_data 卷，辅助文件保存在 app_data 卷；备份时同时保存两者及 .env。应用默认端口 3001，可通过 APP_PORT / APP_BIND_IP 调整宿主机端口与地址，容器覆盖 HOST / PORT / DATABASE_URL。PostgreSQL 不发布宿主机端口，数据库密码必须配置，无默认密码。初始化脚本自动生成十六进制随机密码和固定配置加密密钥，写入私有 .env；自行设置的数据库密码如含连接串保留字符需编码。容器以非 root 用户运行，健康检查访问最小状态接口 /api/health，日志限制为每个服务 3 个 10MB 文件。

## 验证

```sh
npm run build
npm test
npm run test:e2e
```

浏览器验证需要本地 Chrome，或安装 Playwright Chromium；BROWSER_EXECUTABLE 可指定路径。测试使用隔离的临时数据，不修改实际账号或错题。

- Node 测试覆盖本地 / PostgreSQL 的身份认证、角色权限、归属隔离、来源页面、批量校验、旧数据接收、会话撤销、密钥加密、配置即时生效、AI 请求协议、识别校验、额度及备份迁移去重。
- Chrome 测试覆盖首次建号、1440 / 390 / 320px 页面、裁框拖动与撤销、批量导入与原图回看、刷新持久化、用户管理、空间隔离、手动回退、后台提示词 / 思考等级配置、同页编辑、多图切换保留草稿，以及上传后自动识别。
- PostgreSQL 测试使用 pg-mem，AI 测试使用本地模拟上游；尚未连接真实 PostgreSQL 或调用真实 AI 供应商。真实手机的拍照与触摸手势仍需设备实测。

## 公开仓库与隐私

本仓库不包含实际账号、用户错题、上传照片、数据库备份、运行日志、API 密钥或部署配置。示例题和 public/samples 配图均为虚构演示素材，不来自真实用户资料。

仅提交空值配置模板 .env.example。运行时生成的 .env、data/、settings.key、备份和构建产物均由 .gitignore 排除。请勿用 git add -f 强制加入这些文件。测试代码中的密码和 API Key 是专用虚构占位值，不能用于真实部署。

如需重新生成示例图片，在安装 Chrome 的开发环境执行 npm run samples:generate；运行时直接使用仓库内的 PNG / JPEG，无需生成图片。
